Cat Game 🐱😼😺

A cute cat theme matching game built with Python and Tkinter. Place cats on the board, match three identical cats horizontally, vertically, or diagonally, and keep scoring before the board fills up to the top!

Features

Three difficulty levels: Easy, Normal, and Hard

Mouse-based controls

Matching in horizontal, vertical, and diagonal directions

Current-score and high-score tracking

How to Run

1. Install Python 3.

2. Clone this repository:
git clone https://github.com/sbs0301/Cat-Game.git
cd Cat-Game

3. Start the game:
python3 main.py

Tkinter is included with most Python installations. If it is missing, install the Tkinter package for your operating system before running the game.

How to Play

1. Choose a difficulty level from the opening screen.

2. Move the mouse over the board and click a cell to place the next cat.

3. Match three identical cats in a row horizontally, vertically, or diagonally to clear them and earn points.

4. Continue making matches before the cats reach the top of the board.
